# ADR-014 — Payments Pilot persistence

Decision date: 2026-06-13
Status: Accepted

Database choice: PostgreSQL

The team selected PostgreSQL for the fictional Payments Pilot because ledger
updates need transactions and the acceptance criteria require an auditable
reconciliation trail. The decision applies to the pilot only. The existing
document database remains in place for unrelated catalog metadata.

This record supersedes the database proposal discussed in the 2026-06-10
architecture meeting. The retention period remains undecided; see the incident
follow-up in INCIDENT-022.
